# 現在の注力タスク・ブロッカー

## 最新ステータス（2026-08-15 更新）
- 当面は、`docs/foundation/concept.md` にブランド／Webコンセプトだけをまとめ、依頼者との合意を優先する。
- カラーパレットとフォントは固定せず、コンセプト合意後に複数パターンを新規作成して比較検討する。
- 既存のデザイン8案は、依頼者からコンセプトがまとまって共有される前に作成されたため、一旦取り下げる。
- 次回のデザイン案は既存案の改修ではなく、確定したコンセプトに基づく完全な新規案とする。
- 依頼者の好みは、既存案ではパターン②「Community Care」とパターン④「Ringo Pop」に比較的近い。ただし、採用案ではなく嗜好を理解する参考情報として扱う。

## 現在のフェーズ
- **コンセプト整理・合意フェーズ（デザイン制作前）**
- 現在は具体的なカラーパレット、フォント、レイアウト、案数を決めない。
- コンセプト合意までは、新規デザイン案の制作および既存案の本番反映を開始しない。
- 技術方針・アーキテクチャは継続する。詳細は `docs/foundation/architecture.md`。

## 確定済みの技術方針
- 商品ページ：microCMS＋Astro（静的生成）
- ホスティング／DNS：Cloudflare Pages（無料・500ビルド/月・帯域無制限・停止リスクなし）／DNSもCloudflare
- 画像：ビルド時に自社ホスト取り込み配信
- URL：slug＝ローマ字／表示＝正式名称（日本語）
- 独自ドメイン：自分名義で取得
- コスト：月額実質0円（ドメイン年額のみ）

## 次のアクション
1. `docs/foundation/concept.md` の内容を依頼者と確認し、ブランド／Webコンセプトを確定する。
2. 合意後、デザイン案に共通して守る情報要件・アクセシビリティ要件を定義する。
3. カラーパレットとフォントを含めた複数の新規デザイン案について、比較軸と作成条件を決める。
4. 新しい条件に基づいて、既存8案とは切り離したデザイン案を作成する。
5. 比較・選定後にのみ、本番ページへの反映計画を作成する。
