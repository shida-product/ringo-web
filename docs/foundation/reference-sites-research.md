# 参考サイト リサーチ結果（2026-07-30）

`site-concept.md` に挙げられた参考サイトへ実際にアクセスし、構成・トーン・演出を分析した記録。
デザインカタログ（骨格×スキン）の設計根拠として参照する。

## たまごっち公式（最重要参考）
- **構成**: 上から下への「ストーリー型」階層。世界観の語り → ニュース → キャラクター紹介 → シリーズ → 商品 → 動画 → SNS。
- **導線**: 購買（=当薬局なら相談・来局）への心理的距離を段階的に縮める設計。
- **トーン**: 「たまごっち星で暮らしている生物たち」など物語的な語り口。「お部屋にうんちをしちゃったりするけど」のような欠点込みの親しみ表現。
- **デザイン**: パステルピンク・黄・水色。ドット絵GIFをセクション区切りに多用（平成レトロ演出の具体手法）。キャラはメインビジュアルで世界観を語り、実務情報の近くでは控えめ。

## ほぼ日刊イトイ新聞
- **構成**: バナー群 → 詳細記事 → 「読むもの」「お買いもの」「おでかけ」のカテゴリ列。
- **トーン**: 親密で会話的。短い段落の断片列挙で「編集者の思考が透ける」。
- **個人メディアの本質**: 創業者の声が直接届く構造。商業性より思想の共有を優先。→ 代表紹介・ブログを主役にする骨格の根拠。

## サンリオ
- **キャラ活用**: キャラ図鑑をグリッド表示、ページ端に装飾キャラで親密感。キャラごとに背景色を変えて識別。
- **配色**: 白背景で清潔感を保ちつつ、セクションごとの色分けで楽しさを出す。→「ごちゃっと感」と可読性の両立手法。

## ヴィレッジヴァンガード
- **ごちゃっと感の演出**: セクションを階段状に多数配置（TOPICS/GOODS/POP UP/EVENT/SELECT/店員の日常）。「SNSで最新情報をチェック!」を上下で繰り返し接触機会を増やす。
- **手書き・POP感**: 装飾フォント、店員個人の「語りたい！」というカジュアル表現。→「スタッフの人柄」を出す手法。

## フェリシモ
- **トーン**: 「自分らしく、心地よく」など押し付けない共感型コピー。★♪☆など装飾記号でカジュアル感。
- **雑貨屋的楽しさ**: 「バイヤー厳選」のキュレーション感、「猫部」など趣味別コミュニティで帰属意識。商品を物語化して見せる。→ OTC商品の見せ方の参考。

## ちいかわマーケット（公式サイトは403のため代替）
- **導線**: 「キャラクターから探す」「シリーズから探す」「カテゴリから探す」と複数の入口を並列に提示。
- **トーン**: 「こんにちはッ！」などカジュアルな敬語。メニューの下線など小さな遊び心。
- **見せ方**: 背景は白系でシンプルに保ち、商品とバナーの色で楽しさを出す。

## 未調査
- M!LK・あのちゃん・大森靖子: アーティスト公式サイトのため構造面の参考度は低いと判断し割愛。「推し活文脈の語彙」としてコピーライティングに反映する。
- ちいかわ公式（chiikawa-info.jp）: アクセスブロック（403）。

## カタログ設計への示唆（要点）
1. **ストーリー型骨格**（たまごっち）: 世界観 → キャラ → 相談テーマ → 実務情報の順で心理的距離を縮める。
2. **個人メディア型骨格**（ほぼ日）: 代表の声・読みものを最上部に。店舗情報は後方でよい。
3. **雑貨屋型骨格**（ヴィレヴァン/フェリシモ）: セクション多数・情報量多め・スタッフの人格を前面に。
4. **共通手法**: 背景は明るく保ち色数はパーツで稼ぐ（サンリオ/ちいかわ式）、ドット絵・装飾記号で平成レトロ、キャラは「案内役」として世界観パートに置く。
